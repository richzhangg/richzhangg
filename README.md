## 🚀 Featured Projects

<details>
<summary><strong>⚡ UnbiasedNews — Real-Time Political News Aggregator & Bias Analyzer</strong></summary>

<br/>

> An end-to-end NLP news intelligence pipeline that ingests live U.S. news, clusters articles by event, and generates concise cross-source summaries to expose political framing differences.

<div align="center">

| Attribute | Details |
|-----------|---------|
| **Stack** | Python, NewsAPI, HuggingFace BART, SentenceTransformers, spaCy |
| **Scale** | Real-time ingestion of U.S. national news articles across sources |
| **Performance** | 92% full-text extraction accuracy; sub-second clustering per event group |
| **Security** | API key isolation, rate-limiting, and sanitized HTML scraping |
| **Impact** | Enables side-by-side comparison of ideologically distinct coverage of the same event |
| **Repository** | [![GitHub](https://img.shields.io/badge/View%20Repo-6A0DAD?style=flat-square&logo=github&logoColor=white)](https://github.com/richzhangg) |

</div>

Built a two-stage scraping and validation pipeline: the first stage retrieves article URLs from NewsAPI and the second fetches and validates full-text content with fallback handling. Events are grouped via SentenceTransformer cosine similarity before BART generates a unified summary per cluster. Results are exported to JSON for downstream consumption or UI rendering.

</details>
